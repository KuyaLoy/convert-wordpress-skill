# Glossary: the words in plain English

For a developer new to this (profile `level: new`): explain a term in these words the first time it comes up. The
website uses the same list.

| Word | What it means |
|---|---|
| AI agent | An AI app that can run commands and edit files on your computer (Claude Code, Codex, Cursor, Gemini CLI). A chat in the browser alone cannot build the site. |
| Skill | A folder of instructions and tools the agent follows. This one rebuilds a website in WordPress. |
| WordPress | The most used system for running websites. Your team edits words, photos and pages in a dashboard instead of in code. |
| CMS | Content management system: the dashboard where people edit the site without code. WordPress is one. |
| wp-admin | The WordPress dashboard (your site address plus `/wp-admin/`). |
| Local site | A copy of WordPress that runs only on your computer, made with a free app such as Local or Laragon. Nobody else sees it. |
| Golden master | Your current site exactly as visitors see it. The new site is compared with it, page by page. |
| Source | Your current site's files: a GitHub link, a zip or a folder. With only the web address, the agent saves a copy of the pages. |
| 1:1 | The new site looks and works exactly like the old one, at every screen size, at the same web addresses. |
| Sprint | One stage of the work (the plan, the foundation, the pages, the forms, SEO, checks). There are eight before launch. |
| Gate | The stop at the end of a sprint: the agent checks everything, shows you, and waits for your "go". |
| ACF PRO | Advanced Custom Fields PRO, a paid WordPress plugin that gives every page its edit boxes. |
| Secure Custom Fields (SCF) | A free plugin kept by WordPress.org that works like ACF PRO: the same edit boxes, no licence. |
| Contact Form 7 | A free plugin that runs the site's forms and sends their emails. |
| Yoast SEO | A free plugin for page titles, descriptions and other search settings. |
| Duplicator | A plugin that packs the finished site and moves it to your web host (the free version is enough; Pro is paid). |
| Host | The company whose server shows your site to the world (often with a cPanel control panel). |
| Domain | Your site's address, such as example.com. |
| Seeder | A tool in the new site's dashboard that fills every page with your current text and photos, so nothing is typed by hand. |
| Theme | The design files of a WordPress site. The agent builds one from your current site. |
| Handoff files | `handoff.md` and `ai-handoff-summary.md`: notes in the project folder, so any agent or person can continue tomorrow. |
| "The developer" | In the skill's files this means you, the person running the build. |
| Lead | A message someone sends through the site's form. Test leads are sent once the site is live to prove the emails arrive. |
| Redirect (301) | Sends an old web address to the new one, so links and search results keep working. |
